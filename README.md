# Python Data Pipeline with SQLite

## Project Overview

This project demonstrates a simple data pipeline using Python, Pandas, and SQLite.

The pipeline reads sales data from a CSV file, processes and transforms the data, loads it into a SQLite database, and performs SQL-based analysis.

## Data Pipeline

CSV File
↓
Python + Pandas
↓
Data Cleaning & Transformation
↓
SQLite Database
↓
SQL Analysis
